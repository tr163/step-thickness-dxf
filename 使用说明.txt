STEP → 带厚度 DXF 批量转换工具
================================

【怎么用】
1. 把 STEP / STP 文件（可多选）或整个文件夹，拖到「拖到这里转DXF.bat」上
2. 等黑窗口跑完（首次启动 10~20 秒属正常），按任意键关闭
3. DXF 生成在拖进来的文件/文件夹旁边的 dxf_out 里

【输出结构】
dxf_out\
├─ T1.00mm\        ← 文件夹名 = 板厚
│   ├─ 零件1.dxf
│   └─ 零件2.dxf
└─ T2.00mm\

每个 DXF = 一个零件的切割轮廓（外轮廓 + 所有孔），单位 mm，1:1。
一个 STEP 里有多件（装配体）时拆成 名字_1.dxf、名字_2.dxf。

【原理】
取每个实体面积最大的平面作为切割面，沿平面法向压平导出；
厚度 = 实体沿法向的尺寸，写进文件夹名和 DXF 图层名。

【注意】
- 只适合平板类零件：钣金、碳板、玻纤板、亚克力、木板
- 曲面件没有平面，会自动跳过并提示
- 车削件（螺丝、轴）导出的是端面轮廓，不是侧视图，别拿去切割
- 装配体里带的小垫片、螺钉也会各出一个 DXF，
  切割时删掉那些怪厚度（如 T0.44mm / T0.54mm）的文件夹即可
- 本工具自带 Python 环境，免安装，解压即用。
  别单独移动或删除 python 文件夹、step2dxf.py，三个东西要在同一层
- 中文路径没问题；杀毒软件可能首次扫描 python.exe 稍慢，正常

【出问题】
- 双击没反应 / 一闪而过：右键 bat → 编辑，看报错；或把 STEP 单独拖上去试
- 报「读入失败」：文件损坏或不是标准 STEP，先用 CAD 打开另存一次
- 想要侧视图轮廓（车削件）：本工具不支持，需要另外处理
【安全软件】
- 如果电脑装了火绒 / 360 / 联想电脑管家等，可能拦截本工具写文件，
  报「拒绝访问 / WinError 5」：把「STEP转DXF工具」整个文件夹加入
  信任区（白名单），或在弹窗时点「允许」即可。
- 首次运行时安全软件扫描 python.exe 会慢几秒，正常。
